# Growing Moon — Frontend Visual Transformation

## Original problem
Redesign visual presentation & frontend interactions of existing Next.js "Growing Moon" app (founder journey social platform). Preserve 100% content, functionality, routes, Supabase/API contracts, env & config. No backend changes.

## Architecture (unchanged)
Next.js 16 App Router (root /app, webpack), Tailwind 3, motion, lucide-react, Supabase client + external FastAPI (NEXT_PUBLIC_API_URL). `/app/.env` now points NEXT_PUBLIC_API_URL to the user's deployed backend `https://growingmoonbackend.onrender.com` (was localhost default). **KNOWN ISSUE: that backend currently returns HTTP 500 on `/api/feed` and `/api/feed/explore`** — reported to user separately, not a frontend bug, out of agent's control (backend code isn't in this repo).
Preview runner: /app/frontend/package.json shim (supervisor runs `next build && next start` on :3000, no hot reload) — **any CSS/TSX edit requires `sudo supervisorctl restart frontend` to rebuild.**
Supabase OAuth note: user's Supabase project ("pyvaviomgmbohpbfadbv") Site URL/Redirect allow-list must include the live preview/production domain + `/auth/callback`, else Google login redirects to localhost. User was given exact dashboard steps; code-side redirect logic was already correct.

## Implemented (Aug 2026) — Phase 2: Intelligent Content Card System (Home Feed + Explore)
**Scope:** Home Feed + Explore only (Comments/Ask redesign is a separate, not-yet-started phase per user's explicit phasing choice). Sharper/smaller corner radii applied ONLY to feed/explore content cards (rest of app keeps rounded teal pills, per user's choice).
- New reusable media system at `components/feed/media/`: `mediaHelpers.ts` (video provider detection: YouTube/Vimeo/Loom/generic-unknown with graceful "open original" fallback, poster/thumbnail resolution, orientation→aspect-ratio map, hero-tile picker), `SingleMedia.tsx` (single image: portrait=contained/narrow, landscape=full-width; single video: inline play on click + separate fullscreen-expand button), `MultiImageGrid.tsx` (2/3/4/5+ compositions — 4 images shows all 4 in a balanced grid with nothing hidden; 5+ shows hero+3 tiles with an exact `+N` count on the last tile, never silently drops images), `FullscreenMediaViewer.tsx` (shared lightbox/theater viewer — portal to `document.body`, body-scroll lock, Escape/arrow-keys/backdrop/X all close, plays video inline for mixed-media posts per user's choice: single video supports both inline+fullscreen, any post mixing images+video always opens fullscreen), `MediaRenderer.tsx` (top-level dispatcher).
- `components/feed/JourneyPostCard.tsx` fully rewritten (1204→~480 lines): one unified shell (author header → headline/caption → MediaRenderer → action bar → discussion bar) instead of 4 near-duplicate full-article variants; dropped the Instagram-Reels-style full-bleed mobile card (contradicted "not an Instagram clone" + sharp-geometry asks). Sharper `rounded-xl`/`rounded-lg` card & media/button geometry (was `rounded-[28px]`/pills). Text-only posts get a typography-first editorial treatment; journey-tag/date chip now shows on both text-only and media posts.
- `components/explore/ExploreView.tsx`: mobile card format now content-aware (video posts always get the video treatment, text-only gets the minimal card, no more round-robin cycling); fixed video cards to show an honest static Play icon (removed fake Pause/progress-bar/volume icons that implied autoplay); added real poster-image resolution for video banners (was rendering a raw .mp4/YouTube URL as `<img src>`); added media-count (`1/4`) and video-play badges to desktop/mobile cards; text-only desktop cards get a teal gradient hero instead of a misleading stock photo; removed ~340 lines of dead/unused mock data arrays and a purely-decorative animated "neon wave" flourish; fixed remaining purple/lavender leftovers (`#8B5CF6`, `ring-purple-100`, `bg-purple-50`) to teal; sharpened in-card buttons (Follow, View Milestone) to `rounded-md`.
- Bug fixes surfaced during testing: MultiImageGrid tile overflow (absolute-position the `<img>`, `min-h-0` on grid rows), FullscreenMediaViewer backdrop opacity, duplicate "post deleted" toast, inaccurate save/unsave toast wording (fixed in `AppContext.toggleSave`), fake "24" comment-count fallback, "Read more" now measures real `scrollHeight`/`clientHeight` overflow instead of a character-count heuristic (also fixes it correctly re-appearing as "Show less" when expanded), Passport button label responsive (shows "Open" at mobile widths instead of truncating), post 3-dot menu now visible on mobile/tablet (was desktop-only), `ReportModal` now closes on Escape.
- Verified via testing_agent across 3 iterations (iteration_5, iteration_6 + final self-verified fix pass), all CRITICAL/HIGH/MEDIUM issues resolved.
